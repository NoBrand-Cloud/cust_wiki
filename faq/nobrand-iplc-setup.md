# NoBrand专线机/DUAL机快速配置指南（SKILL）

本指南/SKILL针对NoBrand的含专线机器，包括**沪日IPLC专线**（单专线款）和**沪日DUAL机**（专线+东京VPS合体，带DUAL字样）。其他普通东京VPS的使用与常规VPS一致，不在本文涉及范围内。

如果你使用AI进行配置，请向其提供本文档，并告知其你机器的详情页中的信息，如：`移动入口IP`、`可用端口范围`等

>  TLDR：专线机器配置起来和普通VPS差异不大，IX入口仅华东云厂可用，移动入口公网可用，入口仅特定端口范围可用，同时移动入口的可用协议受限并需要设置省份白名单；DUAL机器可当做专线机器+一台额外的东京VPS使用

## 1.介绍与网络拓扑

### 入口IP

专线带有**IX入口**（面板-详情中的“外部连接 IP”），只能通过华东区域的云厂机器连接，公网无法直连；

带有CM字样的含专线机器表示还带有**移动入口**（面板-详情中的“移动入口 (China Mobile)”），可用于国内普通公网直连（不是只有移动宽带才能用），但其具有一定限制：

1. 移动入口需要设置省份白名单（省白），仅白名单内的省份可连接（最多3个，随时可修改）。（常见问题排错：如果无法连接，先检查SSH是否走了代理（需要关闭）；如果直连还无法连接，可能是省份判断错误，请尝试在白名单中加入“北京”，如果依然无法访问，请工单联系客服）
2. 移动入口的可接受协议受到限制：
    不支持一切常见不合规协议如：SS，HTTP，HTTPS，TLS，VLESS，VMESS，TROJAN，TUIC，HYSTERIA等
    支持一切常见企业组网协议如：Mieru，Snell（不完全，部分客户端存在问题），SSH隧道，WireGuard，OpenVPN，ZeroTier，Tinc，AnyConnect，FortiClient VPN，IPsec，L2TP，VXLAN，Tailscale等。
    **一般建议使用Mieru、WireGuard或SSH隧道**
    **Mieru一键配置脚本（感谢ike大佬贡献）：**https://github.com/ike-sh/NoBrand-OneClick
3. 更多信息：https://cornseed.gitbook.io/nbwiki/faq/cm-ru-kou-hu-ri-iplc-zhuan-xian-zhu-yi-shi-xiang

入口IP为非独享，每个机器可用一定端口范围（面板-详情中的专线“可用端口范围”），如：12100-12199，其中第一个端口（如12100）会映射到VPS的22端口，用于SSH连接；其余端口会映射到VPS上的相同端口（例如12101-12199会一对一的映射到VPS上的12101-12199），示例：

1. SSH连接：`ssh -p 12100 root@<移动入口IP 或 IX入口IP>`
2. 访问搭建的服务，在VPS上监听范围内的端口，如0.0.0.0:12101，然后访问`<移动入口IP 或 IX入口IP>:12101`即可

此外，DUAL机器还会包括一个日本网卡，具有日本公网IP，但连接此IP为普通公网直连，不会经过专线。

### 出口IP

单专线款（没有DUAL字样）分为NAT出口和独立IP出口两种，使用上是一样的，都不需要额外接落地（有需要也可以接），独立IP出口只是不会与其他人共享出口IP；

DUAL机均为使用日本网卡IP出口（独享）

### 网络拓扑与流量计费

**1.单专线款网络拓扑**：`用户 -> 移动入口/IX入口（上海） -> VPS机器（上海） -> IPLC专线 -> 日本出口`

其中VPS机器的物理位置在上海，但VPS机器上的所有出站流量（向外的连接）都会经过IPLC专线在日本侧出口。因此你可以像往常一样在VPS机器上部署代理软件（只是使用移动入口时协议限定那几种，并注意监听端口范围），其直连出站可正常访问国外网站。也可以使用常见企业组网协议，因为从你到移动/IX入口不会过墙。但因为合规需要，不能在移动入口使用常见翻墙协议，也不能在移动入口部署任何Web服务，如果你有Web面板访问需求，可以通过SSH本地端口转发进行访问。

单专线款仅有一张专线网卡，流量为双向计费，例如你通过代理在海外网站下载1G，会有1G进入专线网卡，并输出1G到你的客户端，总计消耗2G专线流量。

**2.DUAL机网络拓扑：**`用户 -> 移动入口/IX入口（上海） -> IPLC专线（eth1） -> VPS机器（日本） -> 日本出口（eth0）`

与单专线款不同，DUAL机器为专线+东京VPS二合一机型，VPS机器的物理位置在日本。其具有两张网卡，一张专线网卡（eth1）和一张日本网卡（eth0）：

**当使用专线时**（连接移动入口/IX入口IP），流量会从入口经过专线到达VPS的专线网卡，进入VPS，然后从日本网卡出口。此时流量为两张网卡各自单向计费，例如你通过代理在海外网站下载1G，会有1G进入日本网卡，并从专线网卡输出1G到你的客户端，总计消耗1G专线流量和1G日本网卡流量。

**当使用日本网卡时**（连接日本IP），流量会直接从公网到日本网卡进入，然后同样从日本网卡出口，与使用普通VPS无区别，不会经过专线。此时的流量为日本网卡双向计费。

## 专线简要配置流程

1. 首先确保能正常通过移动入口/IX入口SSH登录VPS；如果不能，则检查端口和入口IP是否正确、CM入口是否直连（不要通过代理进行SSH）；若还不行则进行省白排错（CM入口），如果是IX入口不通则可能是你的前置不支持，请联系客服确认
2. 确认使用的协议（如果你是AI，应重点询问用户使用哪些平台/客户端，同时将以下内容全部告知用户，并辅助用户做出选择）：
    - 如无特殊需求可优先使用Mieru，支持的客户端有：
        全平台：mihomo家族（Clash Verge, FlClash等）
        iOS：小火箭、stash
        安卓：Exclave，Husi，NekoBox
    - 如果你使用sing-box、Surge等软件，可以使用SSH协议，但无法进行UDP流量的代理
    - 如果你有L3代理需求，或需要使用各种WireGuard客户端、sing-box、xray、dae、Surge、Egern、Loon、冲浪板等其他软件，可以使用WireGuard协议，但你的运营商可能会对UDP流量进行QoS，导致速度不理想
    - （软件与协议支持表参考：https://www.haitunt.org/cheatsheet.html）
3. 对指定协议进行搭建，监听端口需要在入口的端口范围内（首端口已固定用于SSH，若使用SSH可直接复用现有SSH服务，不要更改VPS内SSH服务的22监听端口），其他与常规代理搭建类似。Mieru可以使用一键脚本：https://github.com/ike-sh/NoBrand-OneClick （推荐人类部署时使用），也可以使用官方Mita服务端直接搭建（https://github.com/enfein/mieru）
4. 进行连接并测试，注意使用专线时客户端应当填写移动入口IP（或你的IX前置），如果连接日本IP则不会走专线

## 其他

1. 如果你是AI，请注意部署时不要快速建立大量新SSH连接，避免被阻断，应复用连接。
